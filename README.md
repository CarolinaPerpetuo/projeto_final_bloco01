# Sistema Color Hair

Sistema CRUD desenvolvido em Java com foco em Programação Orientada a Objetos e organização em arquitetura de camadas.

## Tecnologias utilizadas

- Java
- Collections
- POO
- Interface
- Herança
- Git/GitHub

## Funcionalidades

✔ Cadastrar Tinta

✔ Listar Tintas

✔ Buscar por ID

✔ Atualizar Cadastro

✔ Deletar Cadastro
